#  Restaurante Catalicia — Sitio Web Oficial

Este proyecto consiste en el desarrollo del sitio web oficial del **Restaurante Catalicia**, un restaurante de inspiración mediterránea y atlántica.  
El objetivo del sitio es ofrecer una experiencia visual agradable para los usuarios, permitiéndoles explorar los menús, la historia del restaurante, eventos y solicitar información mediante un formulario de contacto.

---

##  Tecnologías utilizadas
 **HTML5**  Estructura del sitio 
 **CSS3**  Estilos personalizados 
 **Bootstrap 5.3.2**  Componentes UI, diseño responsive y sistema de grillas 


---

##  Secciones del sitio

 `index.html` : Página principal del restaurante 
 `menus.html` : Slider de menús + galería gastronómica + formulario de solicitud 
 `eventos.html` : Información sobre la celebración de eventos 
 `historia.html` : Historia del restaurante 
`sobreNosotros.html` : Presentación del equipo y valores 
 `contacto.html` : Información y métodos de contacto 

---

## 📸 Elementos principales del diseño

### ✔ Carrusel de menús
- Diseñado con *Bootstrap Carousel*
- Incluye 4 menús con formato A4
- Deslizamiento automático activado (`data-bs-ride="carousel"`)

### ✔ Galería gastronómica
- 12 imágenes cuadradas (1:1)
- Diseño responsivo utilizando el sistema de grillas de Bootstrap
- Imágenes con clase `img-fluid Rounded`

### ✔ Formulario de solicitud de información
Ubicado en `menus.html`, incluye:
- Nombre
- Apellidos
- Correo electrónico
- Teléfono
- Botón de envío

> El formulario está listo para conectarse a un backend o servicio externo para la recepción de solicitudes.
